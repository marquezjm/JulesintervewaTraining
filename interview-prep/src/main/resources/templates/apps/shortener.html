Conceptos Clave en esta Aplicación:

  • Redirección HTTP: El endpoint GET /{shortCode} devuelve una respuesta de redirección (302) para enviar al usuario a la URL original.
  • Generación de Códigos: Se utiliza un contador y codificación Base62 para generar códigos cortos, únicos y amigables para las URLs.
  • Manejo de Estado: Se utiliza un mapa en memoria para almacenar la relación entre el código corto y la URL original. En una aplicación real, esto sería una base de datos (como Redis o una base de datos NoSQL).
