Conceptos Clave de Spring Boot: API RESTful (CRUD)

Este ejercicio demuestra cómo construir una API RESTful completa con Spring Boot. A diferencia de los controladores anteriores que devuelven vistas HTML (@Controller), este usa @RestController para devolver datos en formato JSON.

¿Qué es un @RestController?

Es una anotación de conveniencia que combina @Controller y @ResponseBody. Esto le dice a Spring que todos los métodos en esta clase devolverán datos que se escribirán directamente en el cuerpo de la respuesta, en lugar de resolver una vista. Spring Boot, por defecto, usará la librería Jackson para convertir los objetos Java a JSON.

Endpoints de la API de Usuarios

Puedes probar estos endpoints usando herramientas como Postman, Insomnia, o directamente con curl desde tu terminal.

GET /api/users

Obtiene la lista de todos los usuarios.

curl -X GET http://localhost:8080/api/users
GET /api/users/{id}

Obtiene un usuario específico por su ID.

curl -X GET http://localhost:8080/api/users/1
POST /api/users

Crea un nuevo usuario. El cuerpo de la solicitud debe contener el JSON del nuevo usuario.

curl -X POST http://localhost:8080/api/users \
-H "Content-Type: application/json" \
-d '{"name": "Charlie", "email": "charlie@example.com"}'
PUT /api/users/{id}

Actualiza un usuario existente.

curl -X PUT http://localhost:8080/api/users/1 \
-H "Content-Type: application/json" \
-d '{"name": "Alice Smith", "email": "alice.smith@example.com"}'
DELETE /api/users/{id}

Elimina un usuario.

curl -X DELETE http://localhost:8080/api/users/2
