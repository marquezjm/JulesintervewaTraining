Demostración de Características de Java 8+

Este ejercicio muestra dos de las características más importantes introducidas en Java 8: la API de Streams para el procesamiento de colecciones y Optional para un mejor manejo de nulos.

Datos de Ejemplo (Lista de Empleados)

2. Optional (Manejo de Nulos)

Conceptos Clave Demostrados:

  • API de Streams: Permite un estilo declarativo para procesar colecciones de datos. Se muestra .stream().filter().map().collect().
  • Lambdas y Referencias a Métodos: Sintaxis concisa para la programación funcional (emp -> emp.getSalary() > x y Employee::getName).
  • Optional: Evita NullPointerException al hacer explícito que un valor puede estar ausente. Se muestra .map().orElse().
