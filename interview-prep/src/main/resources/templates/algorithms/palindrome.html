Conceptos Clave en este Ejercicio:

  • Manipulación de Strings: Se normaliza la entrada eliminando espacios y convirtiendo a minúsculas para una comparación correcta.
  • Spring MVC: Uso de @Controller, @GetMapping, @PostMapping, @RequestParam, y Model para manejar la interacción web.
